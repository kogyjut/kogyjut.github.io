# Project Handoff — AI Cloths Finder

## What This Project Is

A personal archive fashion finder hosted on GitHub Pages at **kogyjut.github.io**.  
It shows live clothing listings from Grailed, Depop, and eBay AU — scraped automatically every 8 hours and also on-demand by any user through the scrape button on the site.

---

## What Was Built (Summary)

| Thing | What it does |
|---|---|
| `index.html` | The entire website — card grid, filters, search, the giant scrape button |
| `scraper.py` | Runs on GitHub Actions every 8 hours. Scrapes Grailed for archive brands, writes `data.json` |
| `api.py` | A FastAPI server users hit when they click Scrape. Takes keyword + site, returns live results |
| `.github/workflows/scrape.yml` | The GitHub Action that automates the scraper |
| `render.yaml` | One-click deploy config for hosting the API on Render (free) |
| `data.json` | Generated file — the scheduled scraper writes this, the site reads it |

## Stack

```
GitHub Pages        → hosts index.html (static, free)
GitHub Actions      → runs scraper.py on a schedule (free, 2000 min/month)
Render.com          → hosts api.py (free tier, spins down after 15 min idle)
Scrapling           → Python scraping library (handles anti-bot)
Camoufox            → Stealth Firefox browser Scrapling uses under the hood
FastAPI + uvicorn   → the API framework
```

## Files You Should Never Delete

| File | Why |
